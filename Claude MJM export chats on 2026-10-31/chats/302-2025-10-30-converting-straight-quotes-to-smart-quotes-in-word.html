how can i change all occurrences of straight quotes into smart quotes in Word 365 using the EditReplace dialog?
Claude2025-10-30 17:35 UTC

You cannot directly convert straight quotes to smart quotes using Find & Replace in Word 365 because:

  1. The Replace field interprets your input as literal characters - if you type a smart quote in the "Replace with" field, Word treats it as a straight quote for matching purposes
  2. No special code exists - Unlike ^p for paragraph marks or ^t for tabs, there's noFind & Replace code that tells Word "insert a contextually appropriate smart quote here"

Alternative methods:

  1. AutoFormat feature:

    • Select all text (Ctrl+A)
    • File → Options → Proofing → AutoCorrect Options → AutoFormat tab
    • Check "Straight quotes with smart quotes"
    • Click OK, then run AutoFormat on the document

  2. Enable AutoCorrect going forward:

    • File → Options → Proofing → AutoCorrect Options → AutoFormat As You Type tab
    • Check "Straight quotes with smart quotes"
    • This won't fix existing quotes, but will auto-convert new ones

  3. VBA macro (if you need programmatic control for existing quotes)

Claude2025-10-30 17:36 UTC
Sub ConvertToSmartQuotes()
   Dim doc As Document
   Set doc = ActiveDocument
   
   With doc.Content.Find
       .ClearFormatting
       .Replacement.ClearFormatting
       .MatchWildcards = False
       
       ' Convert straight double quotes to smart quotes
       .Text = """"
       .Replacement.Text = """"
       .Execute Replace:=wdReplaceAll
       
       ' Convert straight single quotes/apostrophes to smart quotes
       .Text = "'"
       .Replacement.Text = "'"
       .Execute Replace:=wdReplaceAll
   End With
   
   MsgBox "Conversion complete.", vbInformation
End Sub

To use:

  1. Press Alt+F11 to open VBA editor
  2. Insert → Module
  3. Paste code
  4. Close editor (Alt+Q)
  5. Run: Alt+F8, select macro, click Run

Warning: This replaces ALL straight quotes uniformly. It won't distinguish between opening/closing quotes contextually—Word's AutoFormat does that intelligently. This macro produces smart quotes but may not orient them correctly in all contexts (e.g., nested quotes, measurements like 5'10").

To convert straight quotes to smart quotes using Find & Replace:

  1. Ctrl+H to open Find & Replace
  2. Find what: "
  3. Replace with: "
  4. Replace All
  5. Find what: '
  6. Replace with: '
  7. Replace All

This works because when you type a smart quote character directly into the Replace field, Word inserts it as-is into the document—it doesn't reinterpret it as a straight quote.

Claude2025-10-30 17:41 UTC

The macro inserts straight quotes because VBA string literals always contain straight quotes, regardless of your AutoCorrect settings.

When you write """" in VBA code, the compiler stores the straight quote character (ASCII 34). AutoCorrect settings that convert straight-to-smart quotes only apply to interactive typing in the Word document interface, not to programmatic text insertion via VBA.

To insert smart quotes in your macro, use character codes:

r.InsertBefore ChrW(8220)  ' Left double smart quote
r.InsertAfter ChrW(8221)   ' Right double smart quote

Character codes:

  • ChrW(8220) = " (left double)
  • ChrW(8221) = " (right double)
  • ChrW(8216) = ' (left single)
  • ChrW(8217) = ' (right single)

Replace the line:

r.InsertBefore """": r.InsertAfter """"

with:

r.InsertBefore ChrW(8220): r.InsertAfter ChrW(8221)
