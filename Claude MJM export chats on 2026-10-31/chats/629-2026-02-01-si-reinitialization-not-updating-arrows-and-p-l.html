Let me see the REINIT detection logic and the arrow clearing code:

Found it. The problem is in the RecalculateAfterReinit() function.

The Issue:

When an SI is REINITed with a structural change (non-cosmetic parameter):

  1. ResetSignalState() is called at line 1061 (from Reinit_ApplyUpdates) — this deletes arrows and sets g_historyProcessed = false
  2. RecalculateAfterReinit() is then called — this recalculates the slope buffers
  3. RecalculateAfterReinit() ends with just ChartRedraw(0) at line 1671

But signal/arrow recalculation in OnCalculate() only happens when:

if(!g_historyProcessed && prev_calculated == 0)   // line 1982

The problem: ChartRedraw(0) doesn't reset prev_calculated to 0. So on the next OnCalculate() call, prev_calculated > 0, and the signal detection block is skipped — even though g_historyProcessed is now false.

Compare with FullRescanAndRebuild() (lines 1333-1351), which correctly uses:

ChartSetSymbolPeriod(0, _Symbol, _Period);   // line 1347

This forces a full recalculation with prev_calculated = 0.

Fix:

In RecalculateAfterReinit(), replace or supplement ChartRedraw(0) with ChartSetSymbolPeriod(0, _Symbol, _Period):

//--- Force full recalculation (resets prev_calculated to 0) so signals get regenerated
ChartSetSymbolPeriod(0, _Symbol, _Period);

Or, alternatively, call the signal detection logic directly within RecalculateAfterReinit() after recalculating the slopes.

Millard2026-02-01 16:42 UTC
What does `ChartSetSymbolPeriod(0, _Symbol, _Period)` do?
Claude2026-02-01 16:42 UTC

It forces the chart to reload by "setting" its symbol and period to the same values it already has. This triggers MT5's internal chart refresh mechanism, which:

  1. Reinitializes the indicator (calls OnDeinit then OnInit)
  2. Calls OnCalculate with prev_calculated = 0

It's essentially a hack to force a full indicator recalculation. MT5 doesn't provide a direct "reset prev_calculated" function, so this is the workaround — you pretend to change the chart's symbol/timeframe, but actually keep them the same, and MT5 treats it as if the chart was freshly loaded.

The side effect is that it reinitializes all indicators on the chart, not just yours. That's why FullRescanAndRebuild() uses it (you want everything reset anyway), but it may be heavier than needed for a single-SI REINIT case.

Alternative fix that avoids the full chart reload: call the signal detection logic directly at the end of RecalculateAfterReinit():

//--- Reprocess signals since buffers changed
datetime time[];
double open[], close[];
ArraySetAsSeries(time, false);
ArraySetAsSeries(open, false);
ArraySetAsSeries(close, false);
CopyTime(_Symbol, _Period, 0, rates_total, time);
CopyOpen(_Symbol, _Period, 0, rates_total, open);
CopyClose(_Symbol, _Period, 0, rates_total, close);

int startBar = iBarShiftREG(_Symbol, PERIOD_CURRENT, InpSignalStartDate);
for(int bar = startBar; bar < rates_total; bar++)
{
   ENUM_SIGNAL_TYPE signal = DetectSignalUP_DN(bar, ARROW_TRADE_ENTRY_LONG, ARROW_TRADE_ENTRY_SHORT, 
                                                time, close, InpSignalPercentMIN, g_signalDirection);
   if(signal != SIGNAL_NONE)
      HandleMockTrades(bar, -g_signalDirection, g_signalDirection, open, close);
}
g_historyProcessed = true;

This recalculates signals immediately without forcing all chart indicators to reinitialize.

//+------------------------------------------------------------------+
//| Recalculate slopes after REINIT (called from ReinitSingleIndicator)|
//| Gets price data and calls CalculateSlopesForLine for reinited lines|
//+------------------------------------------------------------------+
void RecalculateAfterReinit(const int &matchingLines[])
{
   //--- Get current bar count
   int rates_total = Bars(_Symbol, _Period);
   if(rates_total < InpSlopePeriod)
      return;

   //--- Get close prices for ScaledSlope calculation
   double close[];
   ArraySetAsSeries(close, false);
   int copied = CopyClose(_Symbol, _Period, 0, rates_total, close);
   if(copied != rates_total)
   {
//Print("ChartID<",ChartID(),">: ["+__FILE__+"] ["+__FUNCTION__+"] LINE "+(string)__LINE__+
//      " CopyClose failed: requested<", rates_total,"> got<", copied,">");
      return;
   }

//Print("ChartID<",ChartID(),">: ["+__FILE__+"] ["+__FUNCTION__+"] LINE "+(string)__LINE__+
//      " Recalculating ", ArraySize(matchingLines)," lines after REINIT, rates_total<", rates_total,">");

   //--- Track earliest bar for summary buffer update
   int summaryStartBar = rates_total;

   //--- Calculate slopes for each reinited line
   for(int m = 0; m < ArraySize(matchingLines); m++)
   {
      int lineIX = matchingLines[m];

      //--- Force full recalc since ReinitIt was set
      int startBar = CalculateSlopesForLine(lineIX, rates_total, 0, close, true);

//Print("ChartID<",ChartID(),">: ["+__FILE__+"] ["+__FUNCTION__+"] LINE "+(string)__LINE__+
//      " Calculated lineIX<", lineIX,"> shortName<", g_SI_line[lineIX].indicatorShortName,
//      "> startBar<", startBar,">");

      if(startBar < summaryStartBar)
         summaryStartBar = startBar;
   }

   //--- Update summary buffers
   if(g_totalBuffers > 0 && summaryStartBar < rates_total)
   {
      CalculateSummaryBuffers(summaryStartBar, rates_total);
   }

   //--- Reprocess signals since buffers changed
   datetime time[];
   double open[];
   ArraySetAsSeries(time, false);
   ArraySetAsSeries(open, false);
   CopyTime(_Symbol, _Period, 0, rates_total, time);
   CopyOpen(_Symbol, _Period, 0, rates_total, open);

   int signalStartBar = iBarShiftREG(_Symbol, PERIOD_CURRENT, InpSignalStartDate);
   for(int bar = signalStartBar; bar < rates_total; bar++)
   {
      ENUM_SIGNAL_TYPE signal = DetectSignalUP_DN(bar, ARROW_TRADE_ENTRY_LONG, ARROW_TRADE_ENTRY_SHORT, 
                                                   time, close, InpSignalPercentMIN, g_signalDirection);
      if(signal != SIGNAL_NONE)
         HandleMockTrades(bar, -g_signalDirection, g_signalDirection, open, close);
   }
   g_historyProcessed = true;

   //--- Force chart to redraw with new buffer values
   ChartRedraw(0);

//Print("ChartID<",ChartID(),">: ["+__FILE__+"] ["+__FUNCTION__+"] LINE "+(string)__LINE__+
//      " RecalculateAfterReinit COMPLETE");
}
