This function converts a numeric array into a SAX (Symbolic Aggregate approXimation) string.

Process:

  1. Gets array size; returns empty string if empty
  2. Calculates mean and standard deviation of the input data
  3. For each element: computes z-score (value - mean) / std_dev
  4. Maps each z-score to a SAX character via ValueToSAXChar()
  5. Concatenates characters into output string

Result: A symbolic string representation where each character encodes the relative position of each data point within the distribution (e.g., 'a' for low values, 'c' for mid, 'e' for high, depending on your breakpoint configuration in ValueToSAXChar).

Millard2026-01-14 13:25 UTC
what exactly doe the result for (value - mean) / std_dev represent?
Claude2026-01-14 13:26 UTC

The z-score represents how many standard deviations a value lies from the mean.

  • z = 0: value equals the mean
  • z = 1: value is 1 standard deviation above the mean
  • z = -1: value is 1 standard deviation below the mean
  • z = 2.5: value is 2.5 standard deviations above the mean

It normalizes the data to a standard scale regardless of the original units or magnitude, making values comparable across different datasets or time periods.

Millard2026-01-14 13:26 UTC
so that's what a Bollinger band shows?
Claude2026-01-14 13:26 UTC

Yes, conceptually. Bollinger Bands visualize z-score boundaries using a rolling window:

  • Middle band = rolling mean (SMA)
  • Upper band = mean + (k × std_dev), typically k=2
  • Lower band = mean − (k × std_dev)

Price touching the upper band ≈ z-score of +2. Price at middle band ≈ z-score of 0.

Key difference: Bollinger uses a rolling window (e.g., 20 bars) for mean/std_dev. Your SAX encoder calculates mean/std_dev over the entire input array—a fixed lookback, not rolling.
