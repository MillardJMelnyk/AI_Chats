I was hoping that might trigger a reinitialization, but it didn't. Once we have the indicator handle, is there anything in MQL5 that can be done to trigger it to deinit and reinit?
Claude2026-02-03 07:45 UTC

No. IndicatorRelease() only releases your program's reference to the handle—it doesn't affect the indicator instance on the chart.

Options to force reinit:

1. Delete and re-add (requires knowing parameters):

ChartIndicatorDelete(0, window, shortName);
int newHandle = iCustom(_Symbol, PERIOD_CURRENT, "IndicatorSlopes MJM" /*, params */);
ChartIndicatorAdd(0, window, newHandle);

Problem: You likely don't have access to the original input parameters.

2. Force timeframe change (reinits all indicators):

ENUM_TIMEFRAMES current = ChartPeriod(0);
ENUM_TIMEFRAMES temp = (current == PERIOD_M1) ? PERIOD_M5 : PERIOD_M1;
ChartSetSymbolPeriod(0, _Symbol, temp);
ChartSetSymbolPeriod(0, _Symbol, current);

Downside: Reinitializes everything on the chart.

3. Build reinit trigger into the indicator itself: Add a global variable or file flag check inside OnCalculate() that calls ChartSetSymbolPeriod() or returns with prev_calculated = 0 when triggered externally.

4. Template save/load:

ChartSaveTemplate(0, "temp_reset");
ChartApplyTemplate(0, "temp_reset");

Also reinits everything.

There's no surgical IndicatorReinit(handle) function in MQL5. Option 3 is the cleanest if you control the indicator's source code.

#3 what MQL5 statement(s) enable an indicator to reset itself?
Claude2026-02-03 07:46 UTC

For full recalculation only (no OnDeinit/OnInit cycle):

return(0);  // from OnCalculate()

Forces complete recalculation on next tick.

For true OnDeinit → OnInit cycle:

ChartSetSymbolPeriod(0, _Symbol, PERIOD_CURRENT);

Triggers full reinit of all chart indicators, including itself.

There's no self-only surgical reinit. Those are your two options from within indicator code.

void OnStart()
{
   string targetName = "IndicatorSlopes MJM";
   int totalWindows = (int)ChartGetInteger(0, CHART_WINDOWS_TOTAL);

      {
         string shortName = ChartIndicatorName(0, window, i);
         
         if(shortName == targetName)
         {
            // Delete from chart
            if(!ChartIndicatorDelete(0, window, shortName))
            {
               Print("Delete failed. Error: ", GetLastError());
               return;
            }
            
            // Create new instance with known parameters
            int newHandle = iCustom(_Symbol, PERIOD_CURRENT, "IndicatorSlopes MJM",
                                    param1,   // input 1
                                    param2,   // input 2
                                    param3);  // etc.
            
            if(newHandle == INVALID_HANDLE)
            {
               Print("iCustom failed. Error: ", GetLastError());
               return;

            if(!ChartIndicatorAdd(0, window, newHandle))
               Print("Add failed. Error: ", GetLastError());
            else
               Print("Indicator reset successfully.");
            
            return;
         }
      }
   }
   
   Print("Indicator not found.");
}

Replace param1, param2, param3 with actual input values in declaration order. The indicator will execute full OnDeinit → OnInit cycle.

string ReadTextGVar(int instanceID, const string shortName, const string varName, const string defaultValue = "")

//+------------------------------------------------------------------+
//| Read text object value, return default if not found              |
//+------------------------------------------------------------------+
string TextGVar_Read(const string prefix,
                     int instanceID,
                     const string shortName,
                     const string varName,
                     const string defaultValue = "")
{
   string name = TextGVar_BuildName(prefix, instanceID, shortName, varName);
   
   if(ObjectFind(0, name) < 0)
      return defaultValue;
   
   return ObjectGetString(0, name, OBJPROP_TEXT);
}


string TextGVar_BuildName(const string prefix, int instanceID, const string shortName, const string varName)
{
   return prefix + "_" + IntegerToString(instanceID) + "_" + shortName + "_" + varName;
}
