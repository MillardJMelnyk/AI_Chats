what does ATR tell you, and what does the value itself represent. English only, CONCISE.
Claude2026-01-18 13:05 UTC

Sunday, January 18, 2026, 12:40 PM CST

What ATR tells you: Volatility magnitude over a specified period. Not direction—only the average size of price movement.

What the value represents: The mean of True Range values over N periods, expressed in price units (pips, points, dollars—whatever the instrument's quote currency).

True Range = max of:

  • Current High − Current Low
  • |Current High − Previous Close|
  • |Current Low − Previous Close|

ATR of 0.0050 on EUR/USD = average 50-pip movement per bar over the lookback period.

Claude2026-01-18 13:23 UTC

Two factors:

1. ATR measures per-bar range, not cumulative directional movement.

The 40-pip drop was concentrated in fewer, larger-range bars. The 60-pip rise was distributed across more bars with smaller individual True Ranges. A move can travel further in price while producing less per-bar volatility.

2. ATR(9) is a moving average.

As the high-range bars from the drop exit the 9-period lookback window, they're replaced by smaller-range bars from the recovery. ATR declines mechanically even while price continues moving—because the current bars have smaller ranges than the bars being dropped.

Look at the candle bodies/wicks during the drop vs. the rise: the drop has visibly larger individual candles. The rise is choppier, more bars, smaller ranges per bar.

what parameters for the MA does ATR use?
Claude2026-01-18 13:28 UTC

Wilder's Smoothing (SMMA) — not SMA, not standard EMA.

Formula:

ATR = ((Previous ATR) * (N - 1) + Current TR) / N

Equivalent to an EMA with smoothing factor of 1/N.

For ATR(9): smoothing factor = 1/9 ≈ 0.111

This makes it slower to respond than a standard 9-period EMA (which uses 2/(N+1) = 0.2).

Millard2026-01-18 13:31 UTC
Sequentially, in ENGLISH ONLY, no formulas, give me the steps the ATR takes, name inputs and outputs and what it does with them.
Claude2026-01-18 13:31 UTC

Step 1: Get bar data Input: Current bar's High, Low; Previous bar's Close Output: Three values to compare

Step 2: Calculate True Range Compare three distances: High minus Low, absolute distance from High to Previous Close, absolute distance from Low to Previous Close. Take the largest of the three. Output: Single True Range value for current bar

Step 3: Store True Range Add this bar's True Range to a rolling buffer of the last N bars (where N is your ATR period). Output: Buffer of N True Range values

Step 4: Apply Wilder's Smoothing Take previous ATR value, weight it by (N-1), add current True Range, divide total by N. Output: Current ATR value

Step 5: Plot Output ATR value to the indicator subwindow.

Repeat steps 1-5 on each new bar.

so if we had a series of bars whose median hi-lo spreads formed a horizontal line, the ATR would map the variance in their spreads?
Claude2026-01-18 13:34 UTC

No.

ATR would show a smoothed average hovering around that median level, not the variance.

If TR values were 10, 14, 8, 12, 10, 14, 8... (variance around median of 10-11), ATR would output a relatively flat line near the mean (~11), slightly oscillating due to the smoothing lag.

To map variance of True Range, you'd need standard deviation of TR—not ATR.

      bool alreadyChecked = false;
      for(int j = 0; j < checkedCount; j++)
      {
         if(checkedNames[j] == shortName)
         {
            alreadyChecked = true;
            break;
         }
      }
      
      if(alreadyChecked)
         continue;
      
      //--- Add to checked list
      ArrayResize(checkedNames, checkedCount + 1);
      checkedNames[checkedCount] = shortName;
      checkedCount++;
      
      //--- Check for REINIT signal
      string reinitSignal = TextGVar_Read(TEXTGVAR_PREFIX, shortName, "_REINIT", "");
      
      if(reinitSignal == "")
         continue;
      
      Print("REINIT signal detected for indicator: ", shortName);
      
      //--- Get fresh parameters from indicator
      int handle = g_lines[i].indicatorHandle;
      MqlParam params[];
      ENUM_INDICATOR indicator_type;
      int paramsCount = IndicatorParameters(handle, indicator_type, params);
      
      //--- Calculate max period from params[0], params[1], params[2]
      int maxPeriod = 0;
      for(int p = 0; p < MathMin(paramsCount, 3); p++)
      {
         if(params[p].type == TYPE_INT || params[p].type == TYPE_LONG)
         {
            int val = (int)params[p].integer_value;
            if(val > maxPeriod)
               maxPeriod = val;
         }
      }
      if(maxPeriod < 1)
         maxPeriod = 1;
      
      //--- Update all lines belonging to this indicator
      for(int k = 0; k < ArraySize(g_lines); k++)
      {
         if(g_lines[k].indicatorShortName == shortName)
         {
            g_lines[k].period = maxPeriod;
            g_lines[k].lastRatesTotal = 0;  // Force full recalculation
            Print("Updated line ", k, " (", shortName, " ", g_lines[k].lineName, ") period to ", maxPeriod);
         }
      }
      
      //--- Delete the REINIT text object
      TextGVar_Delete(TEXTGVAR_PREFIX, shortName, "_REINIT");
      
      ChartRedraw(0);
   }

                  continue;

               sumSlope   += s;
