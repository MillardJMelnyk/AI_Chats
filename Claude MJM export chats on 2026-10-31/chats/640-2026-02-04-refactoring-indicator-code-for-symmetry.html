//+------------------------------------------------------------------+
//| Find extreme value index within range                             |
//| direction: +1 = highest, -1 = lowest                              |
//+------------------------------------------------------------------+
int FindExtreme(const double &priceArray[], const int depth, const int startIndex, const int direction)
{
   if(startIndex < 0)
      return(0);

   double extremeValue = priceArray[startIndex];
   int extremeIndex = startIndex;

   for(int scanIndex = startIndex - 1; scanIndex > startIndex - depth && scanIndex >= 0; scanIndex--)
   {
      bool isNewExtreme = (direction == 1)
                          ? (priceArray[scanIndex] > extremeValue)
                          : (priceArray[scanIndex] < extremeValue);
      
      if(isNewExtreme)
      {
         extremeIndex = scanIndex;
         extremeValue = priceArray[scanIndex];
      }
   }

   return(extremeIndex);
}

Line behavior logic:

The line value at each bar = the extreme price (highest high or lowest low) within the lookback window ending at that bar.

  • Line flattens when the same extreme persists as the max/min across consecutive bars' lookback windows
  • Line steps when either:
    • A new extreme enters the front of the window (price exceeded previous extreme)
    • The old extreme exits the back of the window (lookback period passed)

The only current control is InpLookbackPeriod:

  • Longer = flatter, slower to react
  • Shorter = more responsive, follows price closely
