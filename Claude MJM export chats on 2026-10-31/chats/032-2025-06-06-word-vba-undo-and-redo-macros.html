Here's VBA code for both Undo and Redo operations in Word:

The main subroutines you need are:

  • UndoLastEdit() - Undoes the last action performed in the document
  • RedoLastEdit() - Redoes the last undone action

Both subroutines include error checking to ensure there are actions available to undo/redo before attempting the operation. They also check if Word is currently recording a custom undo record, which would prevent normal undo/redo operations.

I've also included bonus subroutines for undoing or redoing multiple actions at once, which can be useful if you need to step back several changes.

To use these:

  1. Open the VBA editor in Word (Alt + F11)
  2. Insert a new module (Insert > Module)
  3. Paste the code
  4. Run the subroutines as needed, or assign them to buttons/keyboard shortcuts

The code uses ActiveDocument.Undo and ActiveDocument.Redo methods, which are the standard Word VBA approaches for these operations.
