how do I open Firefox to a select set of tabs/URLs?
Claude2026-09-13 18:43 UTC

Three ways:

1. Command line (opens each URL as a new tab in existing window, or new window if none open):

firefox "https://url1.com" "https://url2.com" "https://url3.com"

2. Force a new window:

firefox -new-window "https://url1.com"
firefox -new-tab "https://url2.com"

3. Persistent set (recommended for repeated use): Bookmark folder → right-click → "Open All in Tabs". Or set browser.startup.page = 3 in about:config to restore the last session, combined with pinning the tabs you want to persist.

For a script/shortcut, a .desktop file or shell alias wrapping option 1 is the simplest durable solution:

alias mytabs='firefox "https://url1.com" "https://url2.com" "https://url3.com"'

Claude2026-09-13 18:59 UTC

Batch files treat % as a variable prefix — %20 gets parsed as %2 (batch argument variable, empty) followed by a literal 0. That's why spaces became 0.

Fix: escape every % as %%.

@echo off
start "" "C:\Program Files\Mozilla Firefox\firefox.exe" "file:///D:/OneDrive/My%%20Stuff%%20(ACV)/My%%20Writing/Blogs%%20and%%20Forums/Facebook/Facebook%%20Graphics/Alondra%%202026-08-28.jpeg" "https://claude.ai/new" "https://mail.google.com/mail/u/0/#label/_+_+_+Unread" "https://www.facebook.com/notifications/" "https://www.youtube.com/watch?v=Tm0b5_oUh7A" "https://ground.news/"
