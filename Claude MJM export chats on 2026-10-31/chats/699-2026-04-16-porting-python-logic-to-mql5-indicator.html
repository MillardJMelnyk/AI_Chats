1. ReadoutToPrice — wrong function body

MQL5 computes value * pip_size / 0.1. For XAUUSD with digits=2, pip_size=0.1, so the result accidentally equals value. For any other symbol (digits=5 → pip_size=0.0001), the MQL5 would return value * 0.001 instead of value. The function body is wrong regardless.

2. ComputeWilderATR — seed computation differs

Python computes TR using close.shift(1), making TR[0] = NaN. The seed is therefore the mean of TR[1]…TR[period−1] — that's period−1 values, excluding bar 0.

MQL5 handles bar 0 with prev_close = bars[0].close, producing TR[0] = high[0]−low[0]. The seed averages period values including bar 0. Different divisor, different first TR. The entire ATR series is shifted/scaled from Python's.

spike_last_price feeds process_spike_intrabar's flip-flop detection. Setting it to extremum instead of close changes when direction reversals are counted.

4. CheckSpikeCondition — spike_pre_spurt_extremum not initialized
