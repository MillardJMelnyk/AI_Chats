Ever since the recent system upgrade for Android, the gboard dictation microphone stopped working. (top right) it responds to the tap, says "initializing" then "speak now" and then immediately stops. Is there anything I can do to get it to work again? I already forced the app and cleared cash.
Claude2025-12-23 13:27 UTC

Try these in order:

  1. Microphone permissions: Settings → Apps → Gboard → Permissions → ensure Microphone is "Allow all the time" or "Allow only while using the app"

  2. Verify Google app has mic access: Settings → Apps → Google → Permissions → Microphone (must be enabled)

  3. Clear Google app cache/data: Settings → Apps → Google → Storage → Clear cache, then Clear data

  4. Re-download voice recognition data: Gboard settings → Voice typing → Offline speech recognition → download your language pack again

  5. Disable battery optimization for Gboard and Google: Settings → Battery → Battery optimization → select "All apps" → find Gboard and Google → set to "Don't optimize"

  6. Uninstall Gboard updates: Settings → Apps → Gboard → three dots (top right) → Uninstall updates → then update from Play Store

Which system update specifically? (Android version or security patch date) This may indicate if it's a known bug.

Gboard app:

  1. Open Gboard settings (tap any text field → tap gear icon, OR Settings → System → Languages & input → On-screen keyboard → Gboard)
  2. Tap "Voice typing"
  3. Tap "Offline speech recognition"
  4. Tap "All" tab
  5. Find your language (e.g., "English (US)")
  6. Tap download icon or tap the language name
  7. Wait for download to complete

Alternative if not in Gboard:

  1. Settings → Apps → Google
  2. Storage → Manage space
  3. "Download offline voice recognition"
  4. Select language

If "Offline speech recognition" option is missing from Gboard, your device may not support it or the feature was removed in your Android version. What Android version are you running?

Re-enable long-press punctuation:

  1. Open Gboard settings (tap text field → gear icon)
  2. Tap "Preferences"
  3. Enable "Long press for symbols"
  4. Verify "Gesture typing" is enabled (Settings → Gboard → Glide typing → toggle on)

If that doesn't work:

  1. Gboard settings → Languages
  2. Tap your language (e.g., English (US))
  3. Tap "Layout"
  4. Ensure it's set to "QWERTY" not "QWERTZ" or other variant

The long-press symbols are layout-dependent. If you cleared data or reinstalled, the layout may have defaulted.

Re-enable symbol hints on keys:

  1. Gboard settings → Preferences
  2. Enable "Long press for symbols" (if not already on)
  3. Enable "Popup on keypress" (this may be required for hints to show)

If hints still don't appear:

  1. Gboard settings → Theme
  2. Try switching to a different theme temporarily, then back to your preferred one
  3. Or select "System auto" or a default theme

Alternative cause:

  • Settings → Gboard → Text correction
  • Disable "Show suggestion strip" temporarily, then re-enable (sometimes forces UI refresh)

The symbol hints (!, ?, ", ', etc. shown small on keys) should reappear once "Long press for symbols" is active and the keyboard UI refreshes properly. Changing themes usually forces the refresh.
