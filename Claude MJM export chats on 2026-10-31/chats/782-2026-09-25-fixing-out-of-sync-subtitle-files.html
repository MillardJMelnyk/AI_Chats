what's the best app for editing .srt files? I have one that's way out of sync with the video.
Claude2026-09-25 22:29 UTC

Friday, September 25, 2026, [time not available] Local

Subtitle Edit (Windows, free) — has a "Change speed/sync" and visual waveform sync tool. Fastest fix: use its "Sync" > "Point Sync via visual sync" feature, or if the offset is constant, "Adjust all times" (add/subtract fixed offset).

If mac/Linux: Aegisub — cross-platform, same waveform-based visual sync, plus a "Timing Postprocessor."

If the desync is a constant offset (not drifting): any text editor + a script works too — .srt timestamps are plain text, so a fixed shift is a one-line regex/arithmetic operation.

If the desync is progressive (framerate mismatch, e.g. 23.976 vs 25 fps): needs a linear rescale, not just an offset — both Subtitle Edit and Aegisub support two-point sync for this case.

Which is it — constant offset or drifting?

Claude2026-09-25 22:35 UTC

Offset: +10,600 ms (video runs 10.6s ahead of your srt timestamps, assuming constant offset — caption 3 is at 00:00:30,400 in the file vs 00:00:41 spoken).

Run: python shift_srt.py input.srt output.srt 10600

Uses a fixed offset (+10,600 ms) for the whole file — won't correct drift or per-scene desync if the source has multiple edit points.
