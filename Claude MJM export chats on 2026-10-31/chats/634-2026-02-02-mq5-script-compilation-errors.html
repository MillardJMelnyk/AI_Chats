Two issues:

1. ArraySort syntax (line 39 in actual source)

MQL5 ArraySort takes only one parameter. You're using MQL4 syntax:

ArraySort(tmp, WHOLE_ARRAY, 0, MODE_ASCEND);  // MQL4 - WRONG

Fix:

ArraySort(tmp);  // MQL5 - correct

2. Array size declarations with const int (causing all the "invalid index value" errors)

MQL5 does not allow const int variables as static array sizes. This fails:

const int TOTAL_BINS = 11;
double hLos[TOTAL_BINS];  // INVALID
int hLongs[TOTAL_BINS];   // INVALID

Fix: Use #define instead:

#define TOTAL_BINS 11

Or use dynamic arrays with ArrayResize().
