Bug 1 — ReadoutToPrice has wrong formula (critical)

Python (line 277):

def readout_to_price(value: float, pip_size: float) -> float:
    return value

The Python function is an identity — it returns value unchanged.

MQL5 (line 243):

double ReadoutToPrice(const double value,const double pip_size)
  { return(value*pip_size/0.1); }

The MQL5 version multiplies by pip_size/0.1, which for digits=2 gives pip_size = 0.1, so the result is value * 1.0 — coincidentally correct for digits=2. But the fundamental contract is wrong: the Python function ignores pip_size entirely. If digits ever changes, they diverge. The correct MQL5 implementation is just return(value);.
