CLAUDE2026-08-09 23:36 UTC

A couple of likely issues:

  1. It's probably just noclip, not cl_noclip. In vanilla Half-Life/GoldSrc, the command is noclip (no arguments, it just toggles on/off each time you type it). The cl_noclip version some guides list may be a Sven Co-op-specific alias, but if it's not working, try the plain noclip command instead.

  2. Cheats need to be on first. Type sv_cheats 1 in console before trying noclip — if cheats aren't enabled, the command will silently fail or print an error.

  3. You need to actually open console properly — press ~ (tilde), and if nothing happens, check that "Enable Developer Console" is turned on in Options > Keyboard, or launch with -console in launch options.

  4. Server restrictions — if you're on someone else's server (not hosting/singleplayer), cheats only work if sv_cheats is set appropriately, and on internet servers cheats are usually restricted to a max of 3 players unless you're an admin/owner. If you're just a regular player on a public server, you likely can't enable it at all.

Try plain noclip first — that's almost certainly the fix.
