MILLARD2026-08-03 19:40 UTC

this script is supposed to convert .pub to .pdf, is it legit?

CLAUDE2026-08-03 19:40 UTC

Yes — it does exactly what it says, no network calls, no downloads, nothing hidden; it drives an installed copy of Microsoft Publisher via COM and exports each .pub to a .pdf next to the original.

MILLARD2026-08-03 19:41 UTC

how do I get it to process these files , each in its own directory so that I end up with the pdfs in the same directories?

CLAUDE2026-08-03 19:41 UTC

From the parent folder, run it with -Filter "*.pub" -Recurse — it writes each PDF beside its source file, so they land in their own directories automatically.

MILLARD2026-08-03 19:42 UTC

what parent folder? There's at least a dozen folders infolved, see image

CLAUDE2026-08-03 19:42 UTC

There isn't one — those paths span four drives (C:, D:, E:, F:), so you run it once per drive root: Convert-PubFileToPDF.ps1 -Filter "C:\*.pub" -Recurse, then again with D:\*.pub, E:\*.pub, F:\*.pub.

Note: the 1 KB ones (id_rsa.pub, id_ed25519.pub, adbkey.pub, LogiKey.pub, logikey.pub) are SSH/device public keys, not Publisher documents — Publisher will choke on them and they'll land in your error count.
