Analysis

Conceptual framework

The state machine is meant to model this cycle:

idle → armed → entered (awaiting exit) → exited → idle (opposite direction)

The five rules you listed map to these constraints:

  1. Only one trade open at a time → can't enter while awaitingExit is true
  2. No exit without prior entry → can't exit while awaitingExit is false
  3. No repeated entry while trade is open → can't enter when already awaitingExit
  4. After exit, next entry must be opposite direction → candidateDir != lastCompletedDir
  5. No two same-direction completed trades in a row → enforced by rule 4

The code has the right shape for this, but there are several concrete inconsistencies and bugs.

Bug 1 — entryArmed can be set while a trade is open

Lines 367–369:

double probNow = BufferProb[i];
if(probNow != EMPTY_VALUE && probNow > InpEntryThresh)
   entryArmed = true;

This runs unconditionally — before the !awaitingExit check. So while a trade is open, entryArmed silently becomes true inside the local variable. That value is then written to g_stateEntryArmed[i] at the bottom. On the next bar, the state starts with entryArmed = true even though a trade is open. If the exit fires on that same next bar before the entry check, the state machine sees awaitingExit = false and entryArmed = true simultaneously, potentially triggering an immediate re-entry in the same direction as the trade that just closed.

Fix: Gate the arming on !awaitingExit:

if(!awaitingExit && probNow != EMPTY_VALUE && probNow > InpEntryThresh)
   entryArmed = true;

Bug 2 — iDir is never reset to 0; the "pending direction" concept is broken

g_stateDir is described by name as a direction, but it serves two roles: the direction of an open trade, and a "default candidate direction" when no trade is open. When the indicator starts cold, iDir defaults to 1. This means every first cold-start entry will be LONG regardless of market conditions — candidateDir begins from iDir and only overrides it if SourceLegDir[i] is non-zero or SourceHighSmooth is valid.

Additionally, when lastCompletedDir == 0 (no trade has completed yet), rule 4's check candidateDir != lastCompletedDir will pass for any direction because 0 never equals 1 or -1. That's actually correct behavior for the very first trade. But iDir == 1 biasing the first entry to LONG is not intentional.

Fix: When not in a trade, iDir should not carry a meaningful value. Compute candidateDir purely from SourceLegDir[i] and SourceHighSmooth/SourceLowSmooth, with no fallback to a stale iDir. If neither source is available, skip entry. Change the candidate derivation block to:

int candidateDir = 0;
if(SourceLegDir[i] != 0.0)
   candidateDir = (int)SourceLegDir[i];
else if(SourceHighSmooth[i] != EMPTY_VALUE && SourceLowSmooth[i] != EMPTY_VALUE)
   candidateDir = (close[i] < SourceHighSmooth[i]) ? 1 : -1;

if(candidateDir != 0 && candidateDir != lastCompletedDir)
{
   // proceed with entry
}

This also adds a candidateDir != 0 guard so entries don't fire when the source has no directional information.

Bug 3 — Exit check uses close[i] but entry arrow uses close[i] too; exit price is wrong

This is a minor conceptual inconsistency. The exit arrow is placed at close[i] (line 409), which is correct. But the band touch condition compares close[i] >= SourceUpper[i]. That's fine. The issue is the exit arrow code is 251 (a circle/dot) with no anchor set, defaulting to ANCHOR_CENTER. This is inconsistent with entry arrows which explicitly set ANCHOR_TOP or ANCHOR_BOTTOM. Not a logic bug, but a display inconsistency — exit arrows may render at unexpected vertical positions relative to price.

Fix: Set ANCHOR_CENTER explicitly on exit arrows for clarity (it's already the default, but making it explicit prevents it from being a future source of confusion).

Bug 4 — Incremental recalc reinitializes state from start = prev_calculated - 1 but state arrays may have stale values for earlier bars

When fullRefresh = false, stateStart = start = prev_calculated - 1. The state machine reads g_state*[i-1] as its prior state. But if bar prev_calculated - 2 had already been computed in a prior call, its state is reused without revalidation. This is correct only if the source buffers for those earlier bars didn't change. Since the channel indicator can repaint earlier bars (its own start walks back to earliestPivotBar - (InpSmoothing - 1)), SourceLegDir and SourceHighSmooth for bars before prev_calculated - 1 may have changed without the state machine re-examining them.

This is the deepest structural issue. The state machine is not a simple per-bar calculation — it's sequential and dependent on history. If any source bar before start changed, the trade sequence from that point forward is potentially wrong.

Fix: When doing an incremental recalc, walk start back to at least minBars if any source data changed. The safest practical approach is to always do a full state recalc (not just probability recalc) on every call where prev_calculated > 0 but walk the probability buffer incrementally. Separate the two loops' start points as you already do, but set stateStart = 0 unconditionally, since the state machine is cheap (no math, just comparisons). Only the probability loop needs the prev_calculated - 1 optimization.

Change line 336:

int stateStart = fullRefresh ? 0 : start;

to:

int stateStart = 0;  // state machine always runs from beginning; source can repaint

Bug 5 — entryArmed is never cleared on exit

When a trade exits, the code sets awaitingExit = false and lastCompletedDir = iDir. But entryArmed is not explicitly cleared. If entryArmed happened to be true at the time of exit (which Bug 1 allows), the state machine will immediately proceed to the entry check on the next bar without going through the arming phase. Combined with Bug 1, this means an exit and a same-bar or next-bar entry can fire in the same direction.

Fix: Add entryArmed = false; inside the exit block alongside awaitingExit = false.

   SetIndexBuffer(3, BufferLowSmooth,     INDICATOR_DATA);
   SetIndexBuffer(4, BufferUpper,         INDICATOR_DATA);
   SetIndexBuffer(5, BufferLower,         INDICATOR_DATA);
   SetIndexBuffer(6, BufferActiveRef,     INDICATOR_DATA);
   SetIndexBuffer(7, BufferLegDir,        INDICATOR_DATA);
   SetIndexBuffer(8, BufferRevisionStart, INDICATOR_DATA);

   PlotIndexSetDouble(0, PLOT_EMPTY_VALUE, EMPTY_VALUE);
   PlotIndexSetDouble(1, PLOT_EMPTY_VALUE, EMPTY_VALUE);
   PlotIndexSetDouble(2, PLOT_EMPTY_VALUE, EMPTY_VALUE);
   PlotIndexSetDouble(3, PLOT_EMPTY_VALUE, EMPTY_VALUE);
   PlotIndexSetDouble(4, PLOT_EMPTY_VALUE, EMPTY_VALUE);
   PlotIndexSetDouble(5, PLOT_EMPTY_VALUE, EMPTY_VALUE);
   PlotIndexSetDouble(6, PLOT_EMPTY_VALUE, EMPTY_VALUE);
   PlotIndexSetDouble(7, PLOT_EMPTY_VALUE, EMPTY_VALUE);
   PlotIndexSetDouble(8, PLOT_EMPTY_VALUE, EMPTY_VALUE);

   handleZZ = iCustom(_Symbol, _Period, "Ind_ZigZag_MJM", InpMinPeriods, InpMinSpread);
   if(handleZZ == INVALID_HANDLE)
      return INIT_FAILED;

   return INIT_SUCCEEDED;
}

//+------------------------------------------------------------------+
int OnCalculate(const int rates_total,
                const int prev_calculated,
                const datetime &time[],
                const double &open[],
                const double &high[],
                const double &low[],
                const double &close[],
                const long &tick_volume[],
                const long &volume[],
                const int &spread[])
{
   if(rates_total < 2)
      return 0;
   if(BarsCalculated(handleZZ) < rates_total)
      return prev_calculated;

   double BufferZZ[], BufferHigh[], BufferLow[];
   if(CopyBuffer(handleZZ, 0, 0, rates_total, BufferZZ) <= 0)
      return prev_calculated;
   if(CopyBuffer(handleZZ, 1, 0, rates_total, BufferHigh) <= 0)
      return prev_calculated;
   if(CopyBuffer(handleZZ, 2, 0, rates_total, BufferLow) <= 0)
      return prev_calculated;

   int start = 0;
   if(prev_calculated > 0)
   {
      int needPivots = MathMax(InpAvgPeriod, InpOffsetLookback) + 1;
      int highsFound = 0;
      int lowsFound = 0;
      int earliestPivotBar = rates_total - 1;
      bool foundAnyPivot = false;

      for(int j = rates_total - 1; j >= 0 && (highsFound < needPivots || lowsFound < needPivots); j--)
      {
         if(highsFound < needPivots && BufferHigh[j] != EMPTY_VALUE)
         {
            highsFound++;
            earliestPivotBar = j;
            foundAnyPivot = true;
         }

         if(lowsFound < needPivots && BufferLow[j] != EMPTY_VALUE)
         {
            lowsFound++;
            if(!foundAnyPivot || j < earliestPivotBar)
               earliestPivotBar = j;
            foundAnyPivot = true;
         }
      }

      if(foundAnyPivot)
      {
         start = earliestPivotBar - (InpSmoothing - 1);
         if(start < 0)
            start = 0;
      }
      else
      {
         start = prev_calculated - 1;
         if(start < 0)
            start = 0;
      }

      if(start < prev_calculated - 1)
         BufferRevisionStart[rates_total - 1] = (double)start;
      else
         BufferRevisionStart[rates_total - 1] = EMPTY_VALUE;
   }
   else
   {
      BufferRevisionStart[rates_total - 1] = EMPTY_VALUE;
   }

   for(int i = start; i < rates_total; i++)
      BufferZZPlot[i] = BufferZZ[i];

   ArrayResize(g_highRaw, rates_total);
   ArrayResize(g_lowRaw, rates_total);

   for(int i = start; i < rates_total; i++)
   {
      double highSum = 0.0;
      double lowSum = 0.0;
      int highCount = 0;
      int lowCount = 0;

      for(int j = i; j >= 0 && (highCount < InpAvgPeriod || lowCount < InpAvgPeriod); j--)
      {
         if(highCount < InpAvgPeriod && BufferHigh[j] != EMPTY_VALUE)
         {
            highSum += BufferHigh[j];
            highCount++;
         }

         if(lowCount < InpAvgPeriod && BufferLow[j] != EMPTY_VALUE)
         {
            lowSum += BufferLow[j];
            lowCount++;
         }
      }

      if(highCount > 0)
      {
         double avgHigh = highSum / highCount;
         g_highRaw[i] = (avgHigh + (close[i] * InpCurrentWeight)) / (1.0 + InpCurrentWeight);
      }
      else
         g_highRaw[i] = close[i];

      if(lowCount > 0)
      {
         double avgLow = lowSum / lowCount;
         g_lowRaw[i] = (avgLow + (close[i] * InpCurrentWeight)) / (1.0 + InpCurrentWeight);
      }
      else
         g_lowRaw[i] = close[i];
   }

   for(int i = start; i < rates_total; i++)
   {
      if(i < InpSmoothing)
      {
         BufferHighSmooth[i] = g_highRaw[i];
         BufferLowSmooth[i] = g_lowRaw[i];
         continue;
      }

      double highSmoothSum = 0.0;
      double lowSmoothSum = 0.0;
      for(int s = 0; s < InpSmoothing; s++)
      {
         highSmoothSum += g_highRaw[i - s];
         lowSmoothSum += g_lowRaw[i - s];
      }

      BufferHighSmooth[i] = highSmoothSum / InpSmoothing;
      BufferLowSmooth[i] = lowSmoothSum / InpSmoothing;
   }

   for(int i = start; i < rates_total; i++)
      BufferMid[i] = 0.5 * (BufferHighSmooth[i] + BufferLowSmooth[i]);

   int lastPivotType = 0;
   for(int j = 0; j < start; j++)
   {
      if(BufferHigh[j] != EMPTY_VALUE)
         lastPivotType = 1;
      else if(BufferLow[j] != EMPTY_VALUE)
         lastPivotType = -1;
   }

   for(int i = start; i < rates_total; i++)
   {
      if(BufferHigh[i] != EMPTY_VALUE)
         lastPivotType = 1;
      else if(BufferLow[i] != EMPTY_VALUE)
         lastPivotType = -1;

      if(lastPivotType == -1)
      {
         BufferLegDir[i] = 1.0;
         BufferActiveRef[i] = BufferHighSmooth[i];
      }
      else if(lastPivotType == 1)
      {
         BufferLegDir[i] = -1.0;
         BufferActiveRef[i] = BufferLowSmooth[i];
      }
      else
      {
         BufferLegDir[i] = 0.0;
         BufferActiveRef[i] = EMPTY_VALUE;
      }
   }

   for(int i = start; i < rates_total; i++)
   {
      double upDiff = 0.0;
      double dnDiff = 0.0;
      int upCount = 0;
      int dnCount = 0;

      for(int j = i; j >= 0 && (upCount < InpOffsetLookback || dnCount < InpOffsetLookback); j--)
      {
         if(BufferZZ[j] == EMPTY_VALUE)
            continue;

         int pivDir = 0;
         double pivBase = 0.0;
         if(BufferHigh[j] != EMPTY_VALUE)
         {
            pivDir = 1;
            pivBase = BufferHighSmooth[j];
         }
         else if(BufferLow[j] != EMPTY_VALUE)
         {
            pivDir = -1;
            pivBase = BufferLowSmooth[j];
         }
         else
            continue;

         double offset = (double)pivDir * (BufferZZ[j] - pivBase);
         if(offset > 0.0)
         {
            if(pivDir == 1 && upCount < InpOffsetLookback)
            {
               upDiff += offset;
               upCount++;
            }
            else if(pivDir == -1 && dnCount < InpOffsetLookback)
            {
               dnDiff += offset;
               dnCount++;
            }
         }
      }

      double upperBase = BufferHighSmooth[i];
      double lowerBase = BufferLowSmooth[i];

      if(upperBase == EMPTY_VALUE)
         upperBase = BufferMid[i];
      if(lowerBase == EMPTY_VALUE)
         lowerBase = BufferMid[i];

      BufferUpper[i] = upperBase + (upCount > 0 ? upDiff / upCount : 0.0);
      BufferLower[i] = lowerBase - (dnCount > 0 ? dnDiff / dnCount : 0.0);
   }

   return rates_total;
}
