The actual compile errors are:

  • Line 632: #if 0 — MQL5 doesn't support #if with numeric literals the way C does. MQL5 preprocessor only supports #ifdef, #ifndef, #else, #endif. #if 0 is invalid MQL5 syntax.
  • Line 753: Mismatched #ifdef/#endif — because #if (line 632) was invalid, the #endif (line 753) has no matching opener.

Fix: Replace #if 0 / #endif with #ifdef NEVER_DEFINED_BLOCK / #endif — that's the MQL5-idiomatic way to dead-out a block.

Root cause: MQL5's preprocessor doesn't support #if <expression> — only #ifdef/#ifndef. The #if 0 was syntactically illegal, which cascaded into the #endif mismatch.

Fix applied: #if 0 → #ifdef DEAD_CODE_OLD_MA2_RECALC_TEMA (a symbol that will never be defined). The #endif on line 753 is already correct and now has a valid matching opener.
