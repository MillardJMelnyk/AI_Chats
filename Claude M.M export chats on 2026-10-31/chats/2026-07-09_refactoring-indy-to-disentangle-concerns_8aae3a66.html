You said: delete the line where the marker function forces trading-allowed to true when blocking is turned off, because it's pointless — the trade logic already forces it true in that case, and it starts out true anyway. The detail: that forced-true line lives inside a small "if blocking is off" block at the top of the marker function. That block does two things — the pointless forced-true, AND it also updates the "last rendered" flag and then exits the function early. So there are two ways to do the deletion:

  • Option A: delete only the forced-true line, keep the rest of the block as is.
  • Option B: delete the whole block, letting the function fall through to its normal code (which, with everything true, draws nothing and updates the flag to the same value).
