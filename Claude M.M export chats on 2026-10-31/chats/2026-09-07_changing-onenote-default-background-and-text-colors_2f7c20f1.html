Changing OneNote default background and text colors

MILLARD2026-09-07 21:21 UTC

In onenote the default background is black with grey font whenever i make a new notebook, page ect. how do i change it to standard white background with black text?

CLAUDE2026-09-07 21:21 UTC

View tab → toggle Dark Mode off; if it stays dark, also set File → Options → General → Office Theme to White.

If you're on OneNote for Windows 10 (the Store app), it's the … menu → Settings → Options → Dark Mode → Off instead.

MILLARD2026-09-07 21:22 UTC

i dont see any dark mode off option, give me a real answer not some bs u make up

CLAUDE2026-09-07 21:22 UTC

The View tab in your build has no Dark Mode button — that toggle is called Switch Background, only appears when the Office Theme is Black, and only flips the page canvas anyway. The real switch is the theme:

File → Options → General → under Personalize your copy of Microsoft Office → Office Theme: White → OK → restart OneNote.

If it's currently set to "Use system setting," that's what's making it black — Windows is in dark mode. Picking White explicitly overrides it.

Page background per page is separate: View → Page Color → No Color.
