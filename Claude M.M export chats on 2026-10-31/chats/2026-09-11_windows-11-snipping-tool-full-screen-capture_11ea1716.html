how do I get the win 11 snipping tool to automatically take a full screen print?

CLAUDE2026-09-11 20:57 UTC

Set Snipping Tool's mode dropdown to Full screen — it keeps that mode, so the next trigger captures the whole screen with no dragging.

Two ways to trigger it:
- PrtScn — turn on Settings → Accessibility → Keyboard → "Use the Print screen key to open screen capture"
- Win + Shift + S — same thing, no settings change needed

If you want it saved to a file automatically with no Snipping Tool window at all, use Win + PrtScn — it drops a PNG straight into Pictures\Screenshots.

That's the key — usually labeled PrtScn, PrtSc, or Print Scr, top-right row near F12.
